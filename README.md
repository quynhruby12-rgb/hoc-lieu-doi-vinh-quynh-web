# Học liệu số Liên đội Trường Tiểu học Vĩnh Quỳnh

Gói hoàn chỉnh gồm trang chủ, giao diện CSS, JavaScript, dữ liệu JSON, bài kiểm tra và Decap CMS.

## Cấu trúc

- `index.html`: trang web chính
- `admin/index.html`: trang quản trị
- `admin/config.yml`: cấu hình Decap CMS
- `assets/css/style.css`: giao diện
- `assets/js/app.js`: xử lý dữ liệu và bài kiểm tra
- `assets/images/`: hình ảnh
- `assets/images/uploads/`: ảnh tải lên từ Decap CMS
- `data/`: nội dung website
- `quizzes/`: bài kiểm tra
- `netlify.toml`: cấu hình Netlify

Đọc file `HUONG_DAN_THAY_THE_TOAN_BO.txt` trước khi tải lên GitHub.
